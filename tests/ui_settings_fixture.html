GitHub 下载设置

根据当前网络选择官方直连或可信的下载中转服务。设置保存在设备本地，不改变官方来源，也不会自动安装更新。

1选择连接方式 · 2选择下载节点 · 3保存并应用

网络连接

优先使用官方直连。仅在下载文件不稳定时，建议启用“仅下载文件使用中转”。
当前使用官方直连时，本项不会生效。切换到中转模式后使用所选节点；预设地址不保证实时可用。
仅在选用自定义节点时填写。必须使用加密连接，并以 / 结尾。
中转节点暂时不可用时自动尝试官方地址。如果当前网络无法直连，可关闭此选项。
关于校验与可信度

安装前会依据 GitHub Release API 提供的 SHA256 摘要核对安装包，但它不是独立数字签名。若将版本查询也交给中转节点，校验信息同样经过该节点，请仅使用可信服务。
