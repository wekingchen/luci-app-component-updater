# V0.5.4 · MT3600BE UI 回归及 AX6S LuCI 菜单激活待验收

> **当前为修复候选，不等于发布通过**。2026-11-20 用户提供的 MT3600BE 手机 Safari 实机截图暴露严重问题：白色背景的标题覆盖了浅色标题文字、主操作在不可用时仍被高亮、`自动识别` 标签换行、设备信息占据过长滚动区域。V0.5.0 RC1 已公开，不得覆盖。V0.5.1 经 MT3600BE 真机截图确认标题文字可读，然而仍残留 LuCI 主题的蓝色横条、耗屏幕的二级菜单、反代选项不易发现等不足。V0.5.2 只提供新的待验候选，尚需相同真机重新确认。

## 设计与可读性验收标准

- **最低对比度**：正常正文、状态、操作按钮（包括禁用态的解释性文字）在对应背景上的对比度目标至少 4.5:1；不能仅靠不同颜色表示状态。单测计算主要颜色对比度，但对嵌入式 LuCI 主题的最终效果仍需真实浏览器检查。
- **主题隔离**：宿主 GL.iNet LuCI 给 `h2/h3`、`section`、`header`、`cbi-map` 的背景或伪元素可能造成白色遮挡与蓝色装饰条。组件应在本身命名空间内修复，不修改平台导航、其它 LuCI 页面与原生系统菜单；页面宽度不能横向溢出。
- **响应式**：320、360、375、390、430、768、1280px 检查，无横向溢出，标题完整，状态标签不折行，数字版本可换行，按钮至少 44px 高，Safari Safari 底部控件不遮挡操作。
- **紧凑且有层次**：主页面依次是标题/状态、NaiveProxy 版本与下一步操作、设备摘要、可展开的诊断。设备摘要最多四行，固件平台、进程和构建细节移入诊断，不用大面积炫光、渐变堆叠与重复标题。
- **操作逻辑**：未检查/无候选时突出「检查官方更新」；发现适配候选并完成计划校验后才突出「下载并更新」；确认已是最新版时将「重新检查更新」变为普通可选操作，不提示需要首次检查。没有本机恢复包时「恢复上一个版本」不可点击，也不能用 JS 直接打开恢复确认弹窗。
- **功能边界**：更新中三按钮禁用，危险操作二次确认；尚未适配的 APK 固件禁止写入；失败需提示中文；不同格式仍通过各自原生安装器恢复，不会主动重启 PassWall。
- **下载设置**：系统菜单隐藏单独的设置子菜单，但原设置 URL 仍可通过首页‘下载设置’打开。任何模式下都显示预设节点；关闭中转时它仅作为预存设置、不应生效。仅在中转模式显示‘失败时尝试直连’，仅自定义中转时显示 HTTPS 地址。表单保存不改原有 UCI 配置语义；反代只改变传输通路，不改变来源和校验。
- **资源与缓存**：本地 CSS 携带版本查询参数，避免真实路由器升级后 Safari 复用 V0.5.0 旧样式；无第三方字体、图标库与 CDN。

## MT3600BE 2026-11-20 真机截图追踪（待复测）

- **V0.5.1 已确认**：白底浅字和禁用按钮对比度明显改善；原有正常操作与状态可读。
- **V0.5.1 尚有问题**：GL.iNet 导航把下载设置作为白色子菜单大块展示，页面标题后有蓝色主题条；直连状态时无法发现预设节点，失败后直连开关在直连状态下无意义。
- **V0.5.2 改动**：保留有 ACL 的设置页 URL，但不再出现在系统二级菜单；首页标题区提供“下载设置”入口；强化 header、panel、cbi-map 伪元素隔离；预设节点一直可见；失败回退仅在中转模式出现，自定义地址仅在自定义节点条件下出现。
- **注意**：隐藏菜单项仍应允许通过界面直达，不允许直接删除 settings 路由。LuCI 表单依赖会通过 `hidden` / CSS 管理显示，响应式 CSS 不能意外破坏 `hidden` 属性。
- 浏览器校验：`tests/ui_visual_fixture.html` 和 `tests/ui_settings_fixture.html`，覆盖 320/390/1280px、未检查/准备更新、官方直连/文件反代/自定义反代，额外检查模拟 GL 主题注入的蓝色条带。
- **待真机确认**：用户安装 V0.5.2 测试 IPK 后，复查 MT3600BE Safari 首页顶部是否仅剩产品入口、不再有蓝色条带；设置页直连状态是否直接显示四个预设节点；中转模式下保存、切换节点与显示/隐藏控制是否正常。

## 2026-11-20 MT3600BE 已验证的真实设备结果

- **主界面**：用户 V0.5.2 iPhone Safari 截图中，顶部多余子菜单、蓝色主题横条消失，标题、状态、设备信息与详细诊断可读；更新检查后准确显示「已是最新版本」。未对不同 LuCI 主题做全面外推。
- **GitHub 设置**：直连与反代模式选择器可用，四个预设节点可显示；保存后重新进入时配置仍保留。中转模式下「失败尝试官方直连」选项按规则出现。
- **全部中转模式查询**：用户明确报告将连接方式设置为「版本查询与文件下载均使用中转」并成功检查官方版本；该结果是用户真机反馈，而非独立抓包或 CI 自动化验证。**文件下载中转实际是否成功、真实包 SHA256 校验、安装、回滚均尚未验证**。
- **V0.5.3 待测试**：已是最新版时不再提示「请先检查官方更新」，改为普通「重新检查更新」；有旧版备份时允许回滚，无备份时明确说明并禁用。仅修复文案与状态强调，不改变下载代理、RPC 与安装引擎。

## 实机复测清单

1. MT3600BE 的原固件 LuCI 主题、N1 的 LuCI 主题分别打开首页与下载设置，确保所有标题和说明的背景与文字清晰。
2. 用 iPhone Safari 观察 320~430px 页面：主标题、NaiveProxy、等待检查、设备标签、折叠诊断不挤压遮挡；打开/关闭详情不改变已有表单和页面状态。
3. 初始未检查：仅「检查官方更新」突出；下载按钮清晰地显示禁用状态；未找到备份时回滚按钮禁用并解释原因。
4. 官方有可安装新版：更新按钮成为当前主操作；确认弹窗可取消；检查与回滚仍可使用（仅在存在恢复备份时）。
5. 更新执行中、发现非法版本、GitHub API 不可达、云端准备中、恢复未完成、未知 APK 固件分别检查全部提示、禁用态与错误恢复。
6. GitHub 下载设置在直连/仅文件/全部反代下可正常选择、保存；4 个预置地址与自定义 HTTPS 验证正常；不允许把不可信地址跳过摘要验证。
7. 核对实际包版本、RPC 状态、更新器不主动重启 PassWall、IPK/APK 更新和回滚行为未受界面改动影响；必要时执行经授权的完整实机安装/恢复验收。

只有上述浏览器与对应硬件验收完成，才可以声称在该设备和主题上达到正式发布质量。V0.5.3 在完成前保持候选状态；V0.5.2 的真机验收记录不等于 V0.5.3 的真机 UI 已验证。
