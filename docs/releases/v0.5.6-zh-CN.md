# LuCI 组件更新器 V0.5.6 正式稳定版

本次提供 **IPK（opkg）与 APK（APKv3）两种原生管理器安装包**，适用于经过本轮验收的指定设备和固件。首个受支持的更新组件为 **NaiveProxy**。本软件用于更新组件，不负责升级路由器固件。

## 安装包

| 设备与软件包体系 | 发布文件 |
| --- | --- |
| GL-MT3600BE · opkg / IPK | `luci-app-component-updater_0.5.6-3_all.ipk` |
| Redmi AX6S · 已适配固件 / APKv3 | `luci-app-component-updater-0.5.6-r3.apk` |

请同时下载 `SHA256SUMS.txt` 校验文件完整性。IPK 与 APK 是**两种不同格式**，不能混装。

## 本次主要能力

- 中文 LuCI 页面，适配移动端与桌面端。
- 查询 NaiveProxy 官方版本，支持 GitHub 直连或可选反代下载。
- 核对下载文件与发布资产摘要，使用对应固件的原生包管理器执行更新。
- 升级前保留恢复基线，支持管理器自身升级、组件更新及手动恢复上一版本。
- 更新和回滚时保留原有 UCI 配置；AX6S APKv3 额外保护 `/etc/apk/world`。

## 已完成的验证

**AX6S（APKv3，指定固件）：** 真机通过管理器 `0.5.6-r3 → 测试版 r4 → r3` 的网页升级、回滚；NaiveProxy 组件通过 `154.0.8037.49.5-r1 → r3 → r1` 的正常升级、回滚。回滚后原始程序 SHA256 与更新前一致，NaiveProxy 配置和 `/etc/apk/world` 的哈希在更新前后保持一致。

**GL-MT3600BE（IPK/opkg）：** 用户确认已完成实际 IPK 更新与回滚；此前也验证了手机 LuCI 页面、GitHub 反代版本查询与设置保留。仓库尚未归档完整三阶段的终端命令日志，因此不声称拥有未提供的具体版本或哈希记录。

**自动化回归：** 已覆盖原生 opkg 21.02.5 / 24.10.5 软件环境、APKv3、ARM64、软件包安装与恢复、LuCI/rpcd 及相关单元测试。

## 兼容范围与注意事项

- 本次正式版的主要验收目标是 **GL-MT3600BE（IPK）** 和 **指定固件的 Redmi AX6S（APK）**。
- **N1 不要求额外实机测试**，保留通用 IPK 兼容路径；这不代表已经完成 N1 真机认证。
- 没有验证运行中的 PassWall 代理流量、进程热切换、实体设备写入失败和意外断电后的恢复，也不能据此推断其他 APK 固件兼容。
- 已知非阻断问题：组件完成更新或回滚后，旧的 `check_state=ready` 检查状态可能残留；实际 `ready=false` 和已安装版本为准。
- 发布摘要校验**不等于独立数字签名**。请使用可信来源下载，并保留独立的设备管理和恢复通道。

**发布原则：** 本版是经过限定设备正常升级及手动回滚验收的稳定版；后续新版本不会自动继承本次稳定认证，仓库的通用自动发布保护仍然关闭。
